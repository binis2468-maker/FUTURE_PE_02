
FUTURE_PE_02 — AI Content Marketing Using UGC Ads

Project Overview

This project demonstrates the use of structured prompt engineering to create authentic, engaging, and platform-ready User-Generated Content (UGC) advertising for a fictional product.

The project focuses on generating UGC hooks, short-form advertising scripts, and social media captions using a reusable prompt system.

Product

EcoGlow Smart Water Bottle

EcoGlow is a reusable smart water bottle designed to help users track their daily water intake and view water temperature while providing a convenient, leak-proof, and eco-friendly solution for everyday use.

Target Audience

- College students
- Young professionals
- Fitness-conscious customers

Content Platforms

The generated content is suitable for:

- Instagram Reels
- Facebook
- YouTube Shorts

Content Pack

1. UGC Advertising Hooks

10 short-form UGC hooks were generated using different approaches such as:

- Relatable problems
- Personal experiences
- Curiosity
- Unexpected discoveries
- Common mistakes
- Product benefits

See: "outputs/hooks.md"

2. UGC Ad Scripts

3 short-form UGC advertising scripts were created using different content structures:

- Problem → Solution → CTA
- Personal Experience / Testimonial
- Product Demonstration

See: "outputs/ugc_ad_scripts.md"

3. UGC Social Media Captions

5 unique social media captions were created for use with the generated UGC advertisements.

The captions use conversational language, product-focused messaging, calls to action, and relevant hashtags.

See: "outputs/ugc_captions.md"

Prompt Engineering System

The project uses a structured prompt system consisting of three main prompts:

Prompt 1 — UGC Hook Generator

Generates short, attention-grabbing hooks designed for the first few seconds of short-form videos.

Prompt 2 — UGC Ad Script Generator

Transforms product information and selected hooks into complete short-form UGC advertisements using different storytelling structures.

Prompt 3 — UGC Caption Generator

Creates social media captions based on the product brief and generated UGC advertisements.

All prompts are documented in:

"prompts/ugc_ad_prompts.md"

Prompt Design Approach

The prompts were designed to provide:

- Clear role definition
- Product and audience context
- Specific content requirements
- Multiple content variations
- Authentic UGC-style language
- Platform suitability
- Clear output formatting
- Natural calls to action
- Avoidance of exaggerated claims

Outcome

The final content pack demonstrates how prompt engineering can be used to create multiple forms of AI-assisted marketing content from a single product brief.

The workflow produces reusable marketing assets including:

Hooks → Ad Scripts → Social Media Captions
